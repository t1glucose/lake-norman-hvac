Project 01 — Waterfront replacement

Twenty-one years of lake air

The homeowner had been told twice that it “just needed a charge.” The coil was corroded through. We replaced the system with a properly sized variable-speed unit, poured a level pad, and re-routed the line set with new insulation.

Project 02 — System changeout

Same corner, different decade

An aging unit crowded against the house with no service clearance and a line set run straight across the wall. We relocated the pad, opened up clearance on all sides, and tidied the electrical whip and disconnect.

Project 04 — Waterfront install

Sited for the shoreline

Units within a hundred feet of the water live a harder life. This install sits on a raised pad clear of the drip line and the mulch bed, with a coated coil and service clearance on every side.

Small decisions at install time are the difference between a system that lasts eight years down here and one that lasts eighteen.
